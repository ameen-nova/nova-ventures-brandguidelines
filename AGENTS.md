# AGENTS.md

This folder is the Nova Ventures brand guideline and its brand assets: the rules, the logos, the shards and the fonts. Nothing else belongs here. Posters, posts and other creatives are made elsewhere, from these files.

## Read first

1. **`BRAND.md`**: the brand book and single source of truth. Read it in full before changing anything.
2. `index.html`: the same guide, designed for people.

If `BRAND.md` and `index.html` disagree, `BRAND.md` wins.

## Changing the brand

1. Update `BRAND.md` first.
2. Then update `index.html` to match, and check the rendered page, not just the code.
3. Keep the two in step: no rule, colour, file or figure in the guide that isn't in `BRAND.md`.

## Files

| What | Where |
|---|---|
| Brand book | `BRAND.md` |
| Visual guide | `index.html` |
| Logos | `Nova Ventures Logo Package/` (see its `README.txt`) |
| Shards | `Nova Ventures Logo Package/06 Shard/` |
| Fonts | `Fonts/Arsenal/`, `Fonts/Lato/` |
| Reference photos | `images/` (generated placeholders, not for public use) |

## Don't

- Don't edit the logo files or fonts, and don't edit `BRAND.md` unless you're asked to.
- Don't invent facts, figures, quotes or contact details. Leave a `[placeholder]`.
- Don't add creatives, experiments or working files to this folder.
